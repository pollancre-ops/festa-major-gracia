# FestiGràcia

Web app mòbil per consultar la programació de la Festa Major de Gràcia 2026.

## Publicar a GitHub Pages
1. Crea un repositori públic a GitHub, per exemple `festigracia`.
2. Puja **el contingut d’aquesta carpeta** a l’arrel del repositori.
3. Ves a `Settings → Pages`.
4. A `Build and deployment`, selecciona `Deploy from a branch`.
5. Tria `main` i `/(root)` i desa.
6. GitHub et mostrarà la URL pública.

## Funcions
- Vista “Ara” i pròximes 2 hores.
- Programa per dia.
- Cerca i filtres per categoria.
- Favorits amb localStorage.
- Botó “Veure al mapa”.
- “A prop meu” amb geolocalització i OpenStreetMap/Nominatim.
- PWA instal·lable i cachejada.

Les dades provenen de `GRACIA.docx`.
